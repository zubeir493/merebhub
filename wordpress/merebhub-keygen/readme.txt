Connects WooCommerce products, orders, and customer accounts to Keygen licensing.

== Setup ==

1. Activate WooCommerce and Advanced Custom Fields.
2. Activate this plugin.
3. Open MerebHub in WordPress admin.
4. Enter the Keygen account ID and account-level API token.
5. Save and test the connection.
6. Edit a WooCommerce product and select its Keygen product and policy in Product data > MerebHub licensing.
